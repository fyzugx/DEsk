# 引き出しの見た目（ルック）

DEsk の引き出しに入れたプログラムは、引き出しにもともとある物でなければ、アイコンを刷ったカードです。
どれでも見た目を変えられます。右クリック（指なら長押し）で、なれる物の見本のカードが出ます。押した物が、
そのあとの見た目になります。選べるのは：

- その**カード**、そして紙に刷らずにそのまま置いた**アイコン**
- 引き出しの小物（ポケットコンピュータ・方位磁針・フォルダ・メモ帳・ドライバー）と、机の物（電卓・
  タイプライター・ノート・Print のカメラ）
- **ルック**：真上から見た物の絵。誰でも作れます。DEsk にはいくつか付いています（ラジオ、絵の具箱、
  ゲームのコントローラー、ヘッドホン）。あとは自分のものか、誰かのもの
- **画像を選ぶ…**：どこにある画像でも、その場で自分のルックにします

どのプログラムがどの見た目かは `$XDG_CONFIG_HOME/desk/drawer-looks` にプログラムごとに残るので、引き出し
から出して入れ直しても同じです。

## ルック

ルックはフォルダ一つです：

```
teapot/
  look.png   真上から見た物。物の周りは何も無し
  look.ini   名前と、大きさと厚み
```

`look.ini`（全部省けます）：

```ini
[Look]
Name=Teapot
Name[ja]=ティーポット
Name[de]=Teekanne
Size=18          # センチ。置いた時の長い辺
Thick=9          # センチ。高さ＝影の長さ
Order=500        # 同じ場所の中での並び。小さいほど先
Author=Someone
License=CC BY 4.0
Comment=何でも
```

- **Name** は英語、`Name[ja]`・`zh`・`ko`・`es`・`fr`・`de` が DEsk のほかの言葉。無ければフォルダの名前。
- **Size** は置いた時の長さ（2〜40 cm）。代わりに `PixelsPerCm=`（絵の何画素が 1 cm か）を書けば、絵の大きさ
  どおり。どちらも無ければ 14 cm（カードの横幅くらい）。
- **Thick** は影のためだけ。無ければ 1 cm。

### 絵

- **真上から**、引き出しに置いたように寝かせて。
- **右上の奥から照らす**（絵では右上から）。引き出しのランプと同じ向きです。フェルトが暗いので、明るすぎないように。
- **影も、物の周りも無し**（透明）。影は引き出しが付けます：どの物にもある 2 つの影を厚みの分だけと、置いた
  場所のフェルトの明るさ。
- DEsk の物は 1 cm が 40 画素です。読むのは長い辺 1024 画素まで。

切り抜いた写真でも、アイコンでもかまいません。透明な所の無い四角は、四角のまま（フェルトの上の写真のように）
置かれます。

## 作る

`desk-look` がルックを作り、机がそれをどう見せるかを教えます。自分のルックとして作ると、引き出しでの名前
（`own/Teapot`）を言います。`-o フォルダ` でほかの場所に作れます。

```bash
desk-look add teapot.png --name Teapot --size 18     # 画像から。PNG・JPEG・SVG など GTK が読める物
desk-look bake teapot.glb --name Teapot --name-ja ティーポット     # 模型から（Blender で）
desk-look check ~/.local/share/desk/looks/Teapot     # 机でどう見えるか
desk-look where                                      # 自分のルックの場所
```

### 模型から

`desk-look bake` は、DEsk のルックと同じ焼き方で模型を焼きます。Blender（<https://www.blender.org>。PATH に
置くか `DESK_BLENDER` で場所を言う）で、寝かせて真上から、引き出しの光で、周りは何も無しに。`.blend`（中の
物すべて）、`.glb`・`.gltf`、`.obj`、`.fbx`、`.stl`、`.ply` を読みます。物の上を上にしてください。

- 大きさは模型のまま：glTF・FBX・メートルの `.blend` はメートル、ほかは推し量ります（`--units m|cm|mm` で直せます）。
  `--size センチ` でその長さにもできます。
- `--thick センチ`（無ければ模型の高さ）、`--turn 度`（縦の軸で回す）、`--samples N`（96。`--quick` は 16）、
  `--author`・`--license`・`--name-ja` ほかの言葉。
- 1 分ほどです。`--verbose` で Blender の言うことも出ます。

焼いているのは `art/looks/bake.py`（`share/desk/looks` に入ります）で、DEsk のルックも同じ物を使っています
（`art/looks/looks.py`。ラジオなどを素朴な形からスクリプトで組んでいます）。Blender で作った物を自分のスクリプトから
`bake.stage()` と `bake.shoot(物, フォルダ, 名前, 厚み)` で焼くこともできます。

### 引き出しから

見本のカードの最後の**画像を選ぶ…**で、どこにある画像でも選べます（入っているアイコンも：`/usr/share/icons`、
`/usr/share/pixmaps`）。自分のルックになり、そのプログラムがその見た目になって、引き出しが出てきて見せます。

## 置き場所

| | |
| --- | --- |
| `share/desk/looks/`（DEsk を入れた所） | DEsk のもの |
| `$XDG_DATA_DIRS/desk/looks/`（`/usr/local/share`、`/usr/share`） | この機械のみんなのもの |
| `$XDG_DATA_HOME/desk/looks/`（`~/.local/share/desk/looks`） | 自分のもの：フォルダ、または PNG だけ（カードくらいの大きさ） |

カードにはこの順に、場所ごとに `Order`、次に名前の順で並びます。自分のフォルダは `own/<フォルダ>`、みんなのは
フォルダの名前で、同じ名前なら先に見つかった方です。

## 人に渡す

ルックはフォルダそのものです。フォルダを（zip にしてもいい）渡せば、`~/.local/share/desk/looks` に置いた人の
もの、`/usr/local/share/desk/looks` に置けばその機械のみんなのものになります。ほかには何も要らず、何も動きません：
ルックは絵と少しの言葉だけです。
